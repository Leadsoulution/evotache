## Project state

This is a Next.js 16 (App Router) project generated by `create-next-app` and not yet customized — `src/app/page.tsx` still holds the default starter content. Treat this as a greenfield app: there is no established architecture to preserve yet, so early structural decisions (routing layout, component organization, state/data approach) are open.

## Commands

- `npm run dev` — start the dev server (Turbopack, via Next.js) at http://localhost:3000
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint (flat config in `eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript rules)

There is no test runner configured in this repo yet.

## Architecture

- **App Router**: pages/layouts live under `src/app`. `src/app/layout.tsx` is the root layout — it wires up the Geist Sans/Mono fonts via `next/font/google` as CSS variables and sets global `<html>`/`<body>` classes.
- **Styling**: Tailwind CSS v4, configured through PostCSS (`@tailwindcss/postcss` in `postcss.config.mjs`) rather than a `tailwind.config.*` file. Global styles are in `src/app/globals.css`.
- **Path alias**: `@/*` maps to `src/*` (see `tsconfig.json`).
- **TypeScript**: `strict` mode is on.
